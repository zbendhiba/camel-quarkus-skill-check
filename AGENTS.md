# AGENTS.md — Quarkus Project Instructions

This is a Quarkus application.

Default to the **Quarkus Agent MCP** for everything: discovering extensions, loading
skills before writing any code, starting the app in dev mode, running tests, reading
documentation, and invoking the Dev MCP tools of the running application.

Discover the available tools through the agent itself rather than relying on any fixed
list: the Dev MCP tools are dynamic and change with the project's extensions.

Do not run Maven or Gradle commands manually while dev mode is running.
